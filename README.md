# Municode · Sur de la Florida — Life City

Consulta el código de las 107 jurisdicciones de Miami-Dade, Broward y Palm Beach,
ubica el lote con sus fuentes oficiales y modela la masa potencial en 3D
(setbacks, pisos, número de edificios y distancia entre edificios).

Publicado en **https://proyectos-lifecity.github.io/municode-florida/**

Los valores de FAR, altura y setbacks se leen en el código de cada ciudad; esta
herramienta es de prefactibilidad y no reemplaza la verificación oficial.
